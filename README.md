# Pinoqio

**The negotiation copilot whose nose grows when theirs should.**

Pinoqio sits in your Microsoft Teams call as a silent teammate. It listens to the other side, keeps a ledger of every claim and number, flags contradictions and dodged questions, and shows a live deception-cue score built from what was said and how it was said. Once in a while, it speaks up.

Built at **Hacktoberfest Hack Day Barcelona** on 24 October 2026. Per the event rules, all project work starts at the event (11:30 CET). This repository was created the night before and holds only the license and placeholders.

Two lanes, one repo:
- `copilot/`: Pinoqio, the call copilot (Gemma 4 + ElevenLabs).
- `judge/`: our entry for Plata's "A Judge That Learns from an Expert" track.
